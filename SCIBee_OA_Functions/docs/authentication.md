# Authentication

**Module:** `oa_gatekeeper.py`

Provides functions for authentication and access to OpenAgri services using JSON Web Tokens (JWT).

### Features

- **Login:** Authenticate a user and obtain an access token.

- **Validate token:** Check whether a JWT is valid.

- **Refresh token:** Refresh an access token.

- **Logout:** Log out a user.

- **Get services:** Retrieve available OpenAgri services.

### Usage

Authentication requires valid user credentials. Token handling depends on the OpenAgri API.
